# Customer-Churn-Prediction-Using-Machine-Learning
Overview

This project predicts whether a telecommunications customer is likely to discontinue a service using machine learning classification techniques.

The project uses the IBM Telco Customer Churn dataset and includes data cleaning, exploratory data analysis, feature preprocessing, model training, evaluation, and an interactive Streamlit web application for generating predictions.

Project Objectives

- Analyze customer characteristics and churn patterns.
- Prepare numerical and categorical features for machine learning.
- Train and compare classification models.
- Evaluate model performance using multiple classification metrics.
- Estimate churn probability for individual customer profiles.
- Build a web interface for interactive predictions.

Technology Stack

- Language: Python
- Data Analysis: Pandas, NumPy
- Visualization: Matplotlib, Seaborn
- Machine Learning: Scikit-learn
- Web Application: Streamlit
- Development Environment: Google Colab

Dataset

Dataset: IBM Telco Customer Churn

Source: https://www.kaggle.com/datasets/blastchar/telco-customer-churn

The dataset contains customer demographic information, account details, subscribed services, contract types, billing information, and churn labels.

The "Churn" column is the target variable, with "Yes" indicating churn and "No" indicating that the customer stayed.

Project Workflow

1. Data Cleaning

- Loaded the dataset using Pandas.
- Converted "TotalCharges" to a numeric data type.
- Handled invalid or missing total-charge values.

2. Exploratory Data Analysis

- Examined the distribution of churn labels.
- Analyzed churn patterns across contract types.
- Explored customer tenure and monthly charges.
- Visualized relationships among numerical features.

3. Data Preprocessing

- Separated the input features and target variable.
- Excluded the customer ID from model training.
- Split the data into training and testing sets.
- Scaled numerical features.
- Applied one-hot encoding to categorical features.
- Used Scikit-learn pipelines to combine preprocessing and model training.

4. Model Training

The project compares:

- Logistic Regression
- Decision Tree Classifier

5. Model Evaluation

Models are evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- Classification Report

The selected model is based on the F1-Score comparison from the test set.

6. Churn Prediction

The trained model accepts an individual customer profile and produces a predicted churn class and an estimated churn probability.

7. Interactive Web Application

The Streamlit application provides:

- Customer input fields
- Contract, billing, and service details
- A prediction button
- Predicted churn status
- Estimated churn probability

Installation and Usage

1. Clone the repository

git clone https://github.com/YOUR_USERNAME/customer-churn-prediction-ml.git
cd customer-churn-prediction-ml

2. Install dependencies

pip install -r requirements.txt

3. Run the Streamlit application

Ensure "customer_churn_model.pkl" is available in the project directory, then run:

streamlit run app.py

Streamlit will provide a local URL where you can open the application.

Requirements

Create a "requirements.txt" file containing:

pandas
scikit-learn
streamlit
joblib

Add "numpy", "matplotlib", and "seaborn" if you want to reproduce the analysis notebook in the same environment.
